# Acme Tasks

A calm task board for small teams that ship on a weekly rhythm.

> Sample app. Acme Tasks is fictional; it exists so openvidstudio has a real, running product to film.

## Features

- **Board with a one-click new task**: capture a task from anywhere and it lands at the top of Backlog.
- **Insights**: shipped-per-week, cycle time and on-time rate, without a spreadsheet.
- **Launch week projects**: group a sprint's work under one colour.
- Team invites and avatars on every card.

## Run it

```bash
npm install
npm run build && npm run preview   # http://localhost:4173
```
